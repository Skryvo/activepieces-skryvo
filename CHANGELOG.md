# Changelog

## 0.1.0

- Sign in with a Skryvo API key, checked against Skryvo.
- Actions: Write a Post, Design a Picture, Schedule a Post, Plan an Article, Write an Article, Get an Article,
  Publish an Article, Write an Email, Write a Product Listing, and a custom API call.
- Trigger: New Event (post published or failed, article ready or failed, results ready), a signed webhook that
  subscribes when the flow is enabled and unsubscribes when it is disabled.
